# 项目定义

## 产品

- 名称：How to Fish Walkthrough
- 域名：howtofishwalkthrough.com
- 一句话定位：Dazed Games 《How to Fish》的独立攻略、图鉴与进度工具站。
- 目标用户：搜索开局路线、Boss 打法、creature/lure 对应关系和地点进度的玩家。
- 核心价值：用可筛选的 49-creature 数据和清晰攻略路径，快速回答“用什么 lure、去哪里、下一步做什么”。
- 商业模式：未来广告变现；MVP 不放广告位。

## 非目标

- 不冒充官方 Wiki。
- 不把 Developer Island 列为正常主线地点。
- 不把 49 creatures 误写为 49 种普通鱼。
- 不声称尚未实现的计算器或 Tier List Maker。

## 约束

- 全站 Title/H1/Description 使用 Game、Walkthrough 或 Dazed Games 锚定游戏意图。
- 内容证据优先 Steam/官方与可交叉验证的攻略原文。
