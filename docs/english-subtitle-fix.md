# 云视频字幕修复（私有 COS 方案）

公开 GitHub 只提交代码与非内容清单；完整 241 课字幕不提交。私有内容本地文件 `lib/english/subtitle-data.json` 已列入 .gitignore，也不能复制到静态输出。服务器从清单指定的版本化 COS 对象读取，经家庭会话保护后返回课程字幕。

## 已确认原因与实现

迁移版生成器原把所有字幕标志固定 false，静态门禁要求 false；播放器未创建字幕轨道，字幕与逐句数据未迁移。

修复增加鉴权 POST /api/english/subtitles、英文/中英字幕、开关、失败重试和逐句听读。课程目录、云视频签名/续签/换课及原站路由保持。录音、发音评分和完整学习包未迁移。

私有内容约 1.38MB；非内容 subtitle-manifest.json 仅含固定对象 key、SHA-256、字节数、课程ID和每课条数/中文可用标志。固定 key 位于既有第一级 GetObject 前缀内的 _learning/，含内容摘要，不覆盖任何媒体。

服务器复用现有 COS 签名能力，在服务器内部拉取该固定对象；不会把对象签名 URL 返回客户端或写入日志。请求超时10秒，最多2MB，以清单字节数与SHA-256校验，成功仅缓存在进程内存并合并并发读取；失败不缓存。客户端依然只请求同源登录保护接口，响应 private/no-store，Service Worker 不缓存。Vercel includeFiles 只包含目录及非内容清单，不包含全文。
