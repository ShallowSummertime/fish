# Beginner Guide English visual set

This folder contains an original English visual set derived from the gameplay
topics visible in the nine Chinese reference screenshots. It does not reuse the
reference artwork, layout, logos, or creator attribution.

## Files

1. `01-beginner-cover-en.png` — article cover
2. `02-survival-loop-en.svg` — Lighthouse survival and first-cash loop
3. `03-bait-hotspots-en.svg` — bait, lures, and moving-water targets
4. `04-profit-multipliers-en.svg` — trick-shot and grill value loop
5. `05-weapon-ladder-en.svg` — early weapon progression
6. `06-firepower-death-en.svg` — late weapons, attachments, and dropped gear
7. `07-island-route-en.svg` — five-location main story route
8. `08-coop-hazards-en.svg` — revives, storage, and environmental hazards
9. `09-boss-clear-en.svg` — boss route and completion checklist

## Editorial status

- The English has been rewritten for mobile readability rather than translated
  word for word.
- Prices, damage numbers, key bindings, boss names, and island numbering came
  from the supplied screenshots and must be checked against the current game
  build before publication.
- The main progression has five accessible locations: Lighthouse, Forest,
  Desert, Rocks, and Volcano. Some guides call this “four islands” because they
  exclude the default Lighthouse start and count only the four unlocks.
- Source SVGs can be regenerated with
  `node scripts/generate-beginner-cards.mjs`.
