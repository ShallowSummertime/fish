# Homepage gameplay carousel

The four homepage scenes were rebuilt from owner-provided Lighthouse gameplay
frames with the same visual treatment used for the Beginner Guide poster set:
rough low-poly game geometry, muted gray-blue environments, a lightly printed
surface, and a warm paper frame. Platform overlays, Chinese editorial text,
creator handles, and watermarks are not present.

## Files

1. `01-lighthouse-start` — meet the Lighthouse Keeper and begin the opening loop
2. `02-first-catch` — first-person rod, landed catch, and starting dock
3. `03-spider-crab` — first-person knife encounter with Spider Crab
4. `04-forest-route` — Radar-guided boat route toward Forest

The PNG files are the full-resolution project masters. The matching WebP files
are the optimized production versions used by the homepage carousel.
